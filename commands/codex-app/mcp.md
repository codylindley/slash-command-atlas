## What it does

Opens MCP status to show connected servers.

Displays the Model Context Protocol connections available to the chat. It is the quickest way to confirm whether the server you expect Codex to use is connected.

## Reach for it when

- A tool backed by an MCP server is missing or unavailable
- You want to inspect the chat's current external-tool connections

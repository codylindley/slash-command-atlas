# `/fork`

> Copies a local chat into a new local chat or worktree.

- **Product:** OpenAI Codex
- **Surface:** OpenAI Codex in the ChatGPT desktop app
- **Category:** Session lifecycle
- **Data snapshot:** 2026-08-23

## What it does

Copies a local chat into a new local chat or worktree.

Branches from the current local chat so the original remains intact while the copy can take a different direction. Depending on the choice you make, the copy can stay in the same project or use a new worktree.

## Reach for it when

- You want to explore an alternative approach without changing the original chat
- A line of work needs an isolated worktree but should retain the current conversation context

## What it does

Chooses the cloud environment for the chat.

Opens the environment chooser for cloud-backed work. This selects where a cloud chat runs; `/cloud` is the separate command that switches the chat to cloud execution.

## Reach for it when

- The workspace has more than one cloud environment
- A task needs dependencies or configuration from a particular environment

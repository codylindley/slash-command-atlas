## What it does

Compacts the current chat context.

Reduces the accumulated conversation context so a long-running chat can keep going with more room for later work. It preserves the chat rather than starting a new one.

## Reach for it when

- A long chat is approaching its context limit
- You want to continue the same task without carrying every earlier turn verbatim

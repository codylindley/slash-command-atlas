## What it does

Writes a heap snapshot and memory diagnostics for troubleshooting.

The diagnostics JSON is intended for bug reports. The full `.heapsnapshot` contains conversation content and credentials and must not be shared.

> **Note:** Hidden from the command menu; type the complete command. Never upload the .heapsnapshot.

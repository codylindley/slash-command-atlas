- **Data snapshot:** 2026-09-14

## What it does

Lets Claude consult a second model for guidance during a task.

Choose `fable`, `opus`, `sonnet`, or a full model ID, or pass `off`. Ordinary local CLI selections are saved for later sessions; run bare for a picker. In Desktop, headless sessions, and Remote Control, 2.1.260+ provides text forms instead; a bare command reports the current advisor.

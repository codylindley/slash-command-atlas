# `/vim`

> Toggles Vim-style modal editing in the input composer.

- **Product:** GitHub Copilot
- **Surface:** GitHub Copilot CLI
- **Category:** CLI & environment
- **Data snapshot:** 2026-09-14

## What it does

Toggles Vim-style modal editing in the input composer.

Enables normal and insert modes, motions, operators, yank and put, undo, redo, and repeat. The same choice can be saved with the `editorMode` setting.

> **Note:** The 1.0.84-2 prerelease (2026-09-08) makes Vim mode available to everyone. Earlier builds can differ.

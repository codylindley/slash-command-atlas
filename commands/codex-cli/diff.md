## What it does

Shows the Git diff, including untracked files.

Displays staged changes, unstaged changes, and files Git has not started tracking, all inside the CLI. It is the direct inspection companion to `/review`.

## Reach for it when

- You want to inspect the exact edits before committing
- A review finding needs to be checked against the underlying patch

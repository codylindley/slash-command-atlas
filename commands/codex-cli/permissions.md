## What it does

Sets what Codex can do without asking first.

Opens the approval-policy picker so you can relax or tighten permissions during the current session. Documented presets include Auto and Read Only; configured named permission profiles also appear when they are active.

## Reach for it when

- You want to inspect changes before Codex edits or runs commands
- A well-scoped task is pausing for approvals more often than you want

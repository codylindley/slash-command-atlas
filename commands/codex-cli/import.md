## What it does

Imports supported Claude Code or Cursor setup, projects, and chats.

Opens the external-agent import picker and migrates the selected supported artifacts into Codex configuration and local files. Session discovery is documented as up to 50 chats from the previous 30 days.

> **Note:** Unavailable while a task is running, in remote sessions, and while connected to the local app-server daemon.

## What it does

Browses available skills and applies one to the next request.

Opens the skill picker so the next request follows that skill’s instructions. You can also type `$` to mention a skill explicitly, or let Codex select one when the request matches its description.

> **Note:** OpenAI’s Build skills guide names this command for the IDE extension, although it is absent from the extension’s 22-row slash-command table. The popup in your installed extension remains definitive.

## What it does

Manually compacts the VS Code conversation context.

Claude compacts automatically when the context indicator approaches its limit; this triggers the same cleanup earlier from the editor prompt.

## Reach for it when

- The context indicator is nearly full
- A long debugging trail is crowding out the code that now matters

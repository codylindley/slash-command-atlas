## What it does

Drafts a design canvas with editable or exportable artboards.

Creates UI mockups, screen flows, landing pages, or posters as an artifact using a research-preview Claude Design editor. Accounts with saving enabled can publish edits as a new version; other accounts can view and export the draft.

> **Note:** **Desktop inheritance:** Anthropic says the Code tab includes built-in commands, but does not publish this command’s Desktop behavior separately. Terminal and native-app behavior can differ.

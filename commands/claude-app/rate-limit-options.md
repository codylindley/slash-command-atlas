## What it does

Opens options for continuing after a subscription usage limit.

Offers waiting for the reset and continuing automatically, adding usage credits, or upgrading where eligible. Keep the session open if you choose to wait. The wait-and-continue choices require 2.1.234+.

> **Note:** Hidden from the command menu; type the complete command.

**Desktop limitation:** this command opens a terminal panel or controls the terminal renderer, so Desktop refuses it or replaces it with native UI.

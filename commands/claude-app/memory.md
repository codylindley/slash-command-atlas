## What it does

Manages project instructions and automatic memory.

Opens the memory interface to edit `CLAUDE.md` files, enable or disable auto memory, and inspect the entries Claude has accumulated.

> **Note:** **Desktop limitation:** this command opens a terminal panel or controls the terminal renderer, so Desktop refuses it or replaces it with native UI.

## Reach for it when

- Claude keeps missing a stable project convention
- You want to inspect or prune what auto memory has retained
